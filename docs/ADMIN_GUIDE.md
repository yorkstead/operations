# Administrator Guide

This is a living guide to be completed as features ship.

Administrators manage organization profile, memberships, roles/capabilities, locations, module entitlements, workflow configuration, integrations, templates, data import/export, audit review, demo reset, retention, and support access.

Every administrative feature must document prerequisites, least-privilege permission, happy path, validation failures, audit events, recovery/rollback, and user-visible consequences. Dangerous actions require explicit confirmation and must never rely on ambiguous labels.
