# Implementation Playbook

Each engagement follows: Discover → Bound → Design → Build → Verify → Pilot → Launch → Improve.

For every release, maintain a problem statement, current-state map, target workflow, decision log, acceptance criteria, data/integration map, risk register, test plan, training/support plan, release checklist, rollback plan, and measured outcome review.

Prefer vertical slices that deliver one complete user outcome. Demo the slice against representative real work before expanding scope. Separate defects, requested changes, and future ideas. A release is complete only when the user path, permissions, data integrity, failure behavior, documentation, monitoring, and recovery are verified.
